🤖 ABOUT THE PROJECT

AI for a Healthier Future

AgroVision AI is an AI-powered plant disease detection system designed to help identify plant conditions from leaf images.

The system uses the PlantVillage dataset and a MobileNetV2-based deep learning model to classify plant leaf conditions.
